# 📊 Análise de Atendimentos – Clínica Estética

Análise exploratória de dados de atendimentos de uma clínica estética fictícia,
com foco em faturamento, taxa de cancelamento e tendências mensais.

## 🎯 Perguntas de Negócio
- Quais serviços geram mais receita?
- Qual a taxa de cancelamento por profissional?
- Como evoluiu o faturamento mês a mês?
- Quais bairros concentram mais clientes?

## 🛠️ Tecnologias Utilizadas
- Python (Pandas, Matplotlib)
- SQL (SQLite)
- Jupyter Notebook

## 📁 Estrutura do Projeto
- atendimentos.csv → dataset com 500 registros
- analise_clinica.ipynb → notebook com toda a análise
- queries/ → consultas SQL separadas
- graficos/ → visualizações geradas

## 📌 Principais Resultados
- Serviço mais rentável: **Preenchimento Labial**
- Taxa média de cancelamento: **37.6%**
- Melhor mês em faturamento: **2023-09**
